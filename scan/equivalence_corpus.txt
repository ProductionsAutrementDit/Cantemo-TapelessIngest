#
# Format, one entry per line:
#
#     storage_id | path | free-text note
#
# A `#!` line is a DIRECTIVE (`#! name: value`), not a comment. `#` alone
# is a comment. Blank lines are ignored.
#
# EXACTLY three columns. This format has no escaping, so neither a path
# nor a note may contain `|` -- a line with four columns is REFUSED
# rather than mis-split. That costs you a pipe in your notes and buys an
# unambiguous scope: the alternative silently re-parsed `2026/a | b` into
# the path `2026/a`, and the gate then ran, cleanly and confidently, over
# the wrong subtree.
#
# `path` is STORAGE-ROOT-RELATIVE (the same coordinate system as
# Folder.path and VSFile.getPath()). Refused: absolute paths, `..`, a
# path that normalises to the storage root, a path containing `|` (this
# format has no escaping), a duplicate, and a path NESTED inside another
# entry -- the shared subtree would be scanned twice and counted twice.
#
# `path` is a SCAN ROOT, exactly as `scan_tapeless_dir --path` is: the
# walk treats it as a container and scans everything BELOW it, never the
# root folder itself. Name the PARENT of the shoots you want gated.
#
# What a corpus has to cover to be worth ratifying:
#
#   * the five on-disk card shapes tests/tier2/test_red_card_shapes.py
#     enumerates;
#   * at least one shoot whose clips live in a provider sub-path;
#   * at least one FOLDER holding more than 100 matching files. Legacy
#     pages at 100 hits PER FOLDER (`result_number = 100` in
#     `_scan_pass`), not per subtree, so a corpus of small folders never
#     exercises legacy's unsorted `from`/`size` loop at all -- and that
#     loop is the whole reason the reference is run twice;
#   * at least one shoot with a mixed provider population, so
#     `provider_name` attribution is exercised rather than assumed.
#
# Run it with:
#   python manage.py verify_discovery_equivalence --corpus <this file>
#
# Sizing note for whoever ratifies this: the gate walks each entry THREE
# times (legacy, legacy, index). Size the corpus to the maintenance
# window accordingly.
